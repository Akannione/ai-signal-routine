# Screenshot Checklist

Store README and portfolio screenshots for the Streamlit dashboard in this folder.

Run the app from the WSL project root:

```bash
AI_SIGNAL_SAMPLE_MODE=1 streamlit run dashboard.py
```

Capture these views at desktop width first:

- `radar.png` - main signal review view with top ranked signals and operator score details visible.
- `opportunities.png` - Opportunity Radar section showing monetizable or buildable ideas.
- `digests.png` - digest preview area showing email, Slack, and phone digest outputs without real credentials.
- `benchmark.png` - benchmark pack view showing Claude versus Codex tasks and scorecard context.

Optional secondary captures:

- `memory.png` - decision queue or memory notes with safe sample data.
- `mini-projects.png` - mini-project ideas generated from current signal themes.

Before committing screenshots, confirm no real tokens, webhook URLs, phone numbers, email addresses, or private notes are visible.
